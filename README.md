# Pratham-Chikitse 🩺

An AI-powered Android first aid emergency guide application built using Kotlin and Jetpack Compose.

## 📌 Project Overview

Pratham-Chikitse is a mobile application designed to provide quick and easy first aid guidance during emergency situations. The app works as an offline emergency assistant and also integrates Generative AI support for additional help and suggestions.

The goal of this project is to help users respond quickly and correctly during emergencies before professional medical help arrives.

---

## ✨ Features

* 🚑 Emergency first aid guidance
* 🤖 Gemini AI emergency assistant
* 📱 Modern UI using Jetpack Compose
* 📶 Offline emergency information
* 🩹 Step-by-step instructions for emergencies
* ✅ Dos and Don'ts section
* ⚡ Fast and lightweight application
* 🎨 Clean and user-friendly interface

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/Pratham-Chikitse.git
```

### Open in Android Studio

1. Open Android Studio
2. Click "Open"
3. Select the project folder
4. Sync Gradle
5. Run the application

## 🔑 API Setup

To use Gemini AI integration:

1. Create Gemini API Key
2. Add the API key in your Retrofit/API configuration file
3. Rebuild the project
